# Cartograph v2.1.31

Cartograph v2.1.31 adds optional Jev-guided code retrieval with user-supplied credentials and refreshes dependencies and build images.

## Changes

- `cartograph explore` and `cartograph_explore` can use the pinned `jev-1.13.0` model to choose up to seven extra bounded retrieval operations within a 30-second deadline.
- Enable it with `cartograph llm setup . --preset jev --api-key-env TYPESAFE_API_KEY`; only the variable name is stored. The provider receives bounded question and source context.
- Missing credentials, provider errors, and rate limits keep native evidence with an explicit outcome. `--decision native`, summary, and low-token requests bypass Jev.
- `tree-sitter-cuda` 0.21.2 (CUDA tile qualifiers) and `unicode-ident` 1.0.26 (Dependabot #162). Rust 1.98.1 build and Debian 13 smoke images get refreshed digests. See the [dependency audit](https://github.com/adder-factory/cartograph/blob/main/docs/v2/DEPENDENCY-UPDATE-2026-09-22.md).

## Upgrade

Run `cartograph upgrade --apply --project-path <PATH> --json` and require `completed: true`; existing V17 indexes rebuild once. No managed database replacement is needed for a ParadeDB 0.25.9 service; reopen the agent host when required.

**Compatibility:** schema 44 · contract V18 · PostgreSQL 18, ParadeDB 0.25.9 (unchanged).
