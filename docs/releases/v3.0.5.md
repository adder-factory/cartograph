# Cartograph v3.0.5

This release adds telephony configuration support and reduces repeated idle
retention work.

## Changes

- Extract FreeSWITCH XML dialplans, contexts, extensions, SIP profiles, and
  literal includes through the existing XML mode.
- Add Kamailio configuration and route facts, with route resolution scoped to
  local declarations and literal included files.
- Add rtpengine configuration sections and option names. Telephony extraction
  omits option values and preserves unresolved dynamic or ambiguous targets.
- Skip repeated scans and writes after graph retention completes, while
  preserving bounded cleanup progress during new revision reservations.

## Upgrade

Stop the existing native owner cooperatively, then run
`cartograph upgrade --apply --project-path <PATH>` and require `completed: true`.
Start the new owner, check status, and reopen attached MCP hosts. V25 requires
one ordinary reindex even when source is unchanged; refresh embeddings if
semantic readiness requests it.

**Compatibility:** native RocksDB format v1 · generation contract V25 · Rust
1.99.1 / edition 2024. Existing native generations remain readable.
