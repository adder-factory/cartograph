# Cartograph v2.1.38

Cartograph v2.1.38 makes Rust turbofish calls such as `parse::<u32>(text)` name and resolve the function they call.

## Changes

- A turbofish call now records `f`, `module::f`, or `value.f` instead of `f::<T>`, so free-function turbofish calls resolve. On Cartograph's own source, 490 were unresolved before.
- The path or member inside a called turbofish is no longer recorded a second time as a reference or field access. A turbofish used as a value is unchanged.
- Inside macro arguments, commas within `::<..>` no longer split arguments, so `matches!` patterns and `assert!` format strings are read correctly.
- Turbofish calls inside macro arguments are now recorded as calls, the same as outside a macro.

## Upgrade

Run `cartograph upgrade --apply --project-path <PATH>`; it migrates the schema and publishes each project's replacement generation. Existing V19 indexes rebuild once even when source is unchanged; no database service upgrade is needed from v2.1.37.

**Compatibility:** schema 47 · contract V20 · ParadeDB 0.25.11 (unchanged).
