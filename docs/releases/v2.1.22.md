# Cartograph v2.1.22

Cartograph v2.1.22 keeps run-scoped exclusions consistent with freshness, adds bounded heap reclaim and `find --format` (#143–#146).

## Changes

- Capacity errors state the 8 GiB `maxGenerationBytes` maximum and point to excluding generated artifacts. Out-of-range values report the exact `1..=8589934592` range.
- Migration 39 records run-scoped `--exclude` globs on each generation; status, sync, and upgrade replay them. A later explicit index without `--exclude` clears them.
- `cartograph db compact --heap` plans `VACUUM FULL` reclaim; applying requires the `compact-heap-relations` confirmation, verified headroom, and no live leases.
- Failed-generation cleanup deletes its spill rows immediately. `cartograph find` accepts `--format text|json` on every axis; JSON stays the default.

## Upgrade

Run `cartograph upgrade --apply --project-path <PATH> --json` and require `completed: true`; existing generations get an empty run-exclusion policy. Managed database initialization installs `pgstattuple`; external PostgreSQL operators install it explicitly.

**Compatibility:** schema 39 · contract V14 (unchanged).
