# Cartograph v2.1.7

Cartograph v2.1.7 adds 52 game-scripting language modes, reaches zero code-health findings on its own checkout, and introduces a resumable upgrade command.

## Changes

- 126 language modes: native TOML plus 52 game-scripting modes, including Rhai with a dedicated extractor and 51 engine, modding, and narrative languages. See [game scripting coverage](https://github.com/adder-factory/cartograph/blob/main/docs/v2/GAME-SCRIPTING-LANGUAGES.md).
- Shared extensions (`.as`, `.c`, `.cs`, `.qc`, `.d`, `.inf`, `.t`, `.txt`) are classified by content or path. Godot `res://` paths resolve to files; PICO-8 reads only `__lua__`.
- `cartograph upgrade --apply --project-path <PATH>` installs, migrates, re-indexes, runs `doctor`, and repairs MCP pins; rerunning resumes. Cold managed image pulls get a 15-minute budget.
- Code-health fixes are structural: no detector, threshold, or severity was changed and no file was excluded.

## Upgrade

Run `cartograph upgrade --apply --project-path <PATH>`; it publishes V10 evidence. It never silently replaces a managed database container: when replacement is needed it stops with the exact backup and confirmation commands, then resumes when rerun.

**Compatibility:** schema 29 · contract V10 · PostgreSQL 18, `pg_search` 0.25.0, pgvector 0.8.4+.
