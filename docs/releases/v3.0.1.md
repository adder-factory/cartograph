# Cartograph v3.0.1

Large graphs can publish through the native RocksDB owner without retaining
their full canonical tables in the storage queue.

## Changes

- Prepare lossless bounded publication blocks when validated graph facts exceed
  the storage input allowance, preserving canonical identities and stored records.
- Keep preparation under the existing supervisor's task, memory, cancellation
  and deadline controls; release full canonical tables before storage admission.
- Stream UUID-ordered tables, sort references per file and edges per symbol pair,
  and use bounded index arrays for outgoing and incoming adjacency.
- Preserve atomic publication, complete snapshot readers and cleanup on corrupt,
  cancelled or failed publication. Existing resource limits remain unchanged.
- Release consumed publication tables and return their destroyed allocations
  through the original byte reservation so waiting readers can enter earlier.
- Fill the existing write-batch allowance while honoring native row and byte
  limits; retain synchronous WAL durability and per-record cancellation checks.
- Recompute status once when publication changes its generation, preserving the
  original deadline, cancellation and complete-generation fence.
- Keep readiness documentation lengths sparse so empty docstrings do not
  exhaust the existing bounded workspace on large graphs.
- Reap completed stage observers before reusing their task and byte capacity,
  retaining the original deadline, cancellation and unread-output accounting.
- Correct installer completion guidance for embedded RocksDB projects.

## Upgrade

Install this release, stop the existing native owner, run `cartograph upgrade
--apply --project-path <PATH>`, restart the owner and reopen attached MCP hosts.
Large packed graphs use complete reconciliation for later changes; they do not
retain the warm canonical allocation for sparse local edits.

**Compatibility:** native RocksDB format v1 · generation contract V23 · Rust
1.99.0 / edition 2024. Existing native generations remain readable.
