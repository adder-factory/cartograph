# Cartograph v2.1.14

Cartograph v2.1.14 fixes content-search path filtering, partial symbol-batch results, and `sync-if-dirty` collisions with the native watcher.

## Changes

- In `cartograph_find` content search, `pathFilter` is a case-sensitive literal substring of the project-relative path, not a prefix, glob, or regular expression.
- An invalid content regex returns an invalid-arguments diagnostic with the parser category and byte offset, never echoing the pattern.
- `cartograph_node` `symbols` batches no longer abort on an ambiguous name; such inputs are listed in `ambiguous` with up to ten candidates and a `truncated` flag.
- `sync-if-dirty` waits up to five minutes for a competing index lease instead of failing, then accepts that publication or retries its own.

## Upgrade

Run `cartograph upgrade --apply --project-path <PATH>`. Restart or reopen the agent host only when the report requires a new process.

**Compatibility:** schema 37 (unchanged) · contract V13 (unchanged) · PostgreSQL 18, `pg_search` 0.25.1, pgvector 0.8.4+.
