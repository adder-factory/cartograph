# Cartograph v3.0.6

This release fixes graph and review evidence from five reported issues and
refreshes native dependencies.

## Changes

- Attribute JavaScript and TypeScript initializer calls to their enclosing
  callable, restoring `this.#private()` call edges (#198).
- Preserve resolvable graph batch inputs and return bounded ambiguity
  candidates and missing-input diagnostics (#199).
- Report `context_retrieval_failed` with a redacted stage, cause, retry policy,
  and recovery action in text and structured MCP errors (#200).
- Retain partial affected-test evidence; report `truncated_before_any_result`
  when a node limit prevents finding any test (#201).
- Support path-filtered agent audits, explain mode-specific invalid arguments,
  and report uncomputed biomarkers explicitly (#202).
- Update notify to 8.2.1, tree-sitter-ada to 0.9.1, and transitive dependencies;
  refresh Linux image digests and remove the obsolete Windows exception.

## Upgrade

Run `cartograph upgrade --apply --project-path <PATH>` during an approved owner
restart, then reopen attached MCP hosts. V26 requires one ordinary reindex
even when source is unchanged; follow status for semantic refresh requirements.

**Compatibility:** native RocksDB format v1 · generation contract V26 · Rust
1.99.1 / edition 2024. Existing native generations remain readable.
