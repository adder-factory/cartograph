# Cartograph v2.1.6

Cartograph v2.1.6 fixes the eight code-health false-positive and missing-consumer cases tracked in issue #114.

## Changes

- Static TypeScript/TSX JSX no longer counts as executable lines. `high_fan_out` ignores directly contained helpers; `long_parameter_list` skips framework route and entry-point signatures.
- `sql_string_concat` requires an ordered statement shape such as `SELECT ... FROM`; `stale_doc` compares values only for explicit numeric claims such as `default` or `limit`.
- `secrets_handling` separates evidence from actionable exposure, so identifiers used only in safe cryptographic handling no longer become findings.
- Python built-ins and receiver calls get explicit provenance. React `lazy(() => import(...))` and TypeScript `typeof` count as consumers; Python declarations abstain from confident `unused_export`.

## Upgrade

After upgrading, run a normal index so unchanged source publishes V9 evidence; older generations stay readable but report stale until then.

**Compatibility:** schema 28 · contract V9 · PostgreSQL 18, `pg_search`, and pgvector as external services.
