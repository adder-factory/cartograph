# Cartograph v2.1.27

Cartograph v2.1.27 adds Ada/SPARK and VHDL code intelligence, sharpens Rust numerical hazards, and makes the biomarker refresh timeout explicit.

## Changes

- Ada (`.adb`, `.ads`, `.ada`, including SPARK) and VHDL (`.vhd`, `.vhdl`) are indexed; imports resolve by declared compilation-unit name. The registry now has 132 modes.
- Numerical analysis: general `abs(x) <= bound` checks and finite `clamp`/`min`/`max` are no longer hazards; guarded `asin`, `acos`, log, and square-root calls are recognized (#154).
- `biomarkers-refresh` takes `databaseQueryTimeoutMs` / `--database-query-timeout-ms` (1 ms to 30 minutes). `timeoutMs` remains a legacy alias; passing both is rejected (#153).
- New pinned grammars `tree-sitter-ada` 0.1.0 and `arborium-vhdl` 2.18.1.

## Upgrade

Run `cartograph upgrade --apply --project-path <PATH> --json` and require `completed: true`; older generations stay stale until an index publishes V15. Restart the agent host only when the report says `restartRequired: true`.

**Compatibility:** schema 40 · contract V15.
