# Cartograph v2.1.8

Cartograph v2.1.8 removes unused development dependencies and Clap's optional color stack, with no schema or contract change.

## Changes

- Unused agent, extractor, search, and MCP development dependencies are removed; the production all-target dependency graph is eight packages smaller.
- Clap no longer enables its color stack. Help, error context, suggestions, and the `--no-color` flag still work.
- MCP protocol tests own their reference fixture instead of enabling a search-crate test-support feature.

## Upgrade

Run `cartograph upgrade --apply --project-path <PATH>`. There is no migration or contract change, so a current V10 generation stays current.

**Compatibility:** schema 29 (unchanged) · contract V10 (unchanged) · PostgreSQL 18, `pg_search` 0.25.0, pgvector 0.8.4+.
