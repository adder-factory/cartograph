# Cartograph v2.1.17

Cartograph v2.1.17 moves the supported search engine to ParadeDB `pg_search` 0.25.2 and makes managed database upgrades resumable.

## Changes

- Fresh setups create pgvector before `pg_search`; existing installs update pgvector, then `pg_search`, in one transaction.
- Existing indexes using the legacy `bm25` access method stay queryable; new and rebuilt indexes use the `paradedb` name.
- Managed replacement keeps the old container stopped until the new image passes every check. Repeating the confirmed command resumes an interrupted upgrade without manual Docker repair.
- Capability checks require the exact `pg_search` version and `pdb.source_code` tokenization; there is no fallback to plain PostgreSQL full-text search.

## Upgrade

Run `cartograph upgrade --apply --project-path <PATH> --json`. If it reports `requiredConfirmation: upgrade-managed-database`, first create and keep the printed backup, run only the reported `cartograph db upgrade` with that confirmation, then rerun `upgrade --apply` until `completed: true`.

**Compatibility:** schema 38 (unchanged) · contract V14 (unchanged) · PostgreSQL 18.4+ (major 18), `pg_search` 0.25.2, pgvector 0.8.4+.
