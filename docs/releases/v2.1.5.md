# Cartograph v2.1.5

Cartograph v2.1.5 closes ten post-v2.1.4 issues in auto-sync, upgrades and MCP registration, review contracts, and code-health detectors.

## Changes

- Auto-sync keeps stage-specific error codes and retries with 30-second exponential backoff capped at 15 minutes, stopping after five unchanged failures. Project excludes apply before nested worktree traversal.
- Installs register the stable `~/.cartograph-cli/current/bin/cartograph` launcher, and `cartograph upgrade` repairs stale Codex, Claude, and Cursor pins.
- A database schema newer than the binary fails startup with both versions and upgrade guidance.
- `cartograph_affected` file mode enforces `maxNodes` and reports `impact.nodesTruncated`; `cartograph_review` risk mode returns per-lens `ready`, `timeout`, or `unavailable`.
- Precision fixes in `hardcoded_url`, `unused_export`, `forof_await` (honors `cartograph: serial-await`), `high_fan_out`, and `duplicate_code`.

Run a normal index after upgrading to publish current V8 evidence.
