# Cartograph v2.1.30

Cartograph v2.1.30 refreshes the Rust dependencies and moves the supported ParadeDB runtime from 0.25.7 to 0.25.9.

## Changes

- The managed image is pinned to ParadeDB 0.25.9 by digest: PostgreSQL 18.6, `pg_search` 0.25.9, and pgvector 0.8.4 on amd64 and arm64.
- Dependency updates: `toml_edit` 0.25.15 (Dependabot #160), Clap 4.6.7, rustls 0.23.45, ArkTS grammar 0.3.0, OCaml grammar 0.26.0. Linux builds use digest-pinned Rust 1.98.1.
- Managed upgrade recovery tests add 0.25.7 alongside 0.25.3 and 0.25.6.
- Schema 43 admits contract V17: unchanged projects report stale and rebuild once so the new grammars take effect. See the [dependency audit](https://github.com/adder-factory/cartograph/blob/main/docs/v2/DEPENDENCY-UPDATE-2026-09-14.md).

## Upgrade

Run `cartograph upgrade --apply --project-path <PATH> --json`. If it requests a managed database upgrade, verify the reported backup and free space, quiesce project writers, run the confirmed `db upgrade`, then resume until `completed: true`; reopen agent hosts when required.

**Compatibility:** schema 43 · contract V17 · external PostgreSQL 18.4+ (major 18), `pg_search` 0.25.9 exactly, pgvector 0.8.4+ (0.8.6 recommended).
