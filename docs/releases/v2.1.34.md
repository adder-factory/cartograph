# Cartograph v2.1.34

Cartograph v2.1.34 lets large fully embedded projects re-index again, preserves wrapped MCP registrations, and adds command-based LLM credentials.

## Changes

- Publication carries embeddings forward in pages of 4,096, so full re-indexes of projects with about 330,000 embedded documents no longer exceed the three-minute prepare timeout.
- `upgrade --apply` no longer reinstalls wrapper-launched MCP registrations (`/usr/bin/env`, secret managers, `direnv`); it replaces only the embedded Cartograph path and keeps `env`, `cwd`, and arguments (#172).
- Remote LLM tiers can read their key from a command: `llm setup --api-key-command <PROGRAM> --api-key-arg <ARG>` (`apiKeyCommand`). Runs without a shell, bounded to 10 seconds, re-run after 401/403 (#173).
- `apiKeyCommand` is trusted project configuration, so review `.cartograph/config.json` in untrusted checkouts. A failure reports `credential_unavailable` and Jev falls back to native retrieval.
- `doctor` warns instead of failing when an optional tier's `apiKeyEnv` variable is missing from the current shell (#174).

## Upgrade

Run `cartograph upgrade --apply --project-path <PATH>`. No database upgrade is needed from v2.1.33.

**Compatibility:** schema 45 (unchanged) · contract V18 (unchanged) · ParadeDB 0.25.11 (unchanged).
