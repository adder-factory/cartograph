# Cartograph v2.1.43

Cartograph v2.1.43 updates the Rust dependencies and moves the managed database to ParadeDB 0.26.1.

**What changed**

- The digest-pinned managed image supplies PostgreSQL 18.6, `pg_search` 0.26.1, and pgvector 0.8.6 on Linux amd64 and arm64.
- Upgrade recovery now covers the previously shipped 0.26.0 image, including interrupted container replacement and failures around extension-catalog updates. Coverage for 0.25.3, 0.25.6, 0.25.10, and 0.25.11 remains.
- Direct dependencies advance to `serde_json` 1.0.154, SHA-2 0.11.1, `toml_edit` 0.25.17, Tree-sitter 0.27.1, ABAP bindings 33.0.1, and `unicode-ident` 1.0.27. Cargo refreshes compatible transitive dependencies.
- GitHub artifact actions move to download 8.0.2 and upload 7.0.2. Rust 1.99.0 and Debian 13 build/smoke images use refreshed digests. See the [dependency audit](https://github.com/adder-factory/cartograph/blob/main/docs/v2/DEPENDENCY-UPDATE-2026-10-13.md).

**Upgrade**

Run `cartograph upgrade --apply --project-path <PATH>` and require `completed: true`. Follow any exact managed-database confirmation it requests, then reopen attached MCP hosts when required.

**Compatibility:** schema 50 (unchanged) · contract V23 (unchanged) · external PostgreSQL 18.4+ (major 18), `pg_search` 0.26.1, pgvector 0.8.4+ (0.8.7 recommended); managed uses pgvector 0.8.6. Native archives contain only Cartograph and its notices; PostgreSQL and extensions remain separate services.
