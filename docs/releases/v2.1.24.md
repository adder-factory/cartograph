# Cartograph v2.1.24

Cartograph v2.1.24 centralizes workspace dependency declarations, adds a CI check against manifest drift, and updates the ABAP grammar package.

## Changes

- All internal `cartograph-*` crates are declared once in `[workspace.dependencies]` and inherited by members with `workspace = true`.
- A blocking workspace dependency contract rejects missing root declarations, direct member paths or versions, and non-inherited internal dependencies.
- The release-workflow contract rejects job- or step-level `continue-on-error` keys.
- `tree-sitter-abap-sqry` moves from 29.0.6 to 30.0.0. The published parser is byte-identical, so extraction identities and the generation contract are unchanged.

## Upgrade

Run `cartograph upgrade --apply --project-path <PATH> --json` and require `completed: true`. Restart the agent host only when the report says `restartRequired: true`.

**Compatibility:** schema 39 (unchanged) · contract V14 (unchanged).
