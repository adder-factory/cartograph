# Cartograph v2.1.29

Cartograph v2.1.29 moves the supported ParadeDB runtime to 0.25.7 and extends managed-database upgrade recovery coverage.

## Changes

- The managed image is pinned to ParadeDB 0.25.7 by digest: PostgreSQL 18.6, `pg_search` 0.25.7, and pgvector 0.8.4 on amd64 and arm64.
- The supported `pg_search` version is exact, so the Cartograph executable and the database extension must be upgraded together.
- Recovery tests cover 0.25.3 → 0.25.7 and 0.25.6 → 0.25.7, including interrupted replacement and failures before and after extension catalog changes.

## Upgrade

Run `cartograph upgrade --apply --project-path <PATH> --json`. If it requests a managed database upgrade, create and verify the backup, ensure free space, quiesce writers, run the confirmed `db upgrade`, and resume until `completed: true`; do not manually start the old container against the newer catalog.

**Compatibility:** schema 42 (unchanged) · contract V16 (unchanged) · external PostgreSQL 18.4+ (major 18), `pg_search` 0.25.7, pgvector 0.8.4+ (0.8.6 recommended).
