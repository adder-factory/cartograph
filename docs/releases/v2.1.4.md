# Cartograph v2.1.4

Cartograph v2.1.4 adds generation-scoped numerical code intelligence through a new CLI command and MCP tool.

## Changes

- New `cartograph numerical` and `cartograph_numerical` with `sites`, `coverage`, `explain`, and non-executing `plan` modes. The `rust_ast_v1` analyzer reports spans, hazards, precision, confidence, and explicit unknowns.
- Numerical evidence is stored in immutable `numerical_sites` and freshness-fenced; source expressions and literal values are never stored.
- Static, runtime-observation, and formal-proof evidence stay separate; observation and formal adapters report `not_configured`.
- The full MCP profile now publishes 36 tools. The native Windows build runs the resumable v1-import path.

## Upgrade

Run a normal index after upgrading to publish a V7 generation; older generations stay readable but report stale until then.

**Compatibility:** schema 26 · contract V7 · PostgreSQL 18, `pg_search`, and pgvector required.
