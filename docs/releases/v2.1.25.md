# Cartograph v2.1.25

Cartograph v2.1.25 adds a shell-free CLI bridge for generative tiers, hardens managed-database migrations, and protects spill-owned parse-cache rows.

## Changes

- `provider: "cli-bridge"` runs an operator-chosen executable with a bounded argv template that accepts only `{model}` and `{prompt}`, never a shell. Configure via `llm setup` or MCP `llm-plan`/`llm-apply`.
- A database that is behind reports its recorded version, required version, and pending migration. `doctor` checks the schema ledger before reading generation tables.
- Managed image replacement checks free space on the data mount before renaming the healthy container.
- Parse-cache eviction keeps entries referenced by spill rows. Auto-sync opens a circuit after five consecutive failures with one error code. New `db prune --maximum-cascade-rows`.
- Rust 1.98.0, `tree-sitter` 0.26.13, `tree-sitter-sfapex` 3.0.1. Existing `claude-bridge` configurations remain readable.

## Upgrade

Run `cartograph upgrade --apply --project-path <PATH> --json` and require `completed: true`. Restart the agent host only when the report says `restartRequired: true`.

**Compatibility:** schema 39 (unchanged) · contract V14 (unchanged) · PostgreSQL 18, `pg_search` 0.25.3, managed pgvector 0.8.4.
