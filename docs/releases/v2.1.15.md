# Cartograph v2.1.15

Cartograph v2.1.15 makes interrupted indexing recoverable, adds Slang and WESL, reuses embeddings across generations, and tightens code-health rules.

## Changes

- Abandoned staging generations are cleaned before no-op checks; source changing during publication returns `source_changed_during_index` after two retries. Admin index jobs expose live stage and progress (#129, #130, #132).
- New `maxAstDepth` setting (default 256, range 64–1024): deeper files are kept partial with `nesting_limit_exceeded` instead of failing the index (#136).
- Slang (`.slang`) and WESL (`.wesl`) code intelligence; the registry now has 130 modes (#134, #135).
- Embedding sweeps reuse unchanged vectors; reports add `corpus_documents`, `reused_documents`, and `endpoint_documents` (#131).
- Fewer dynamic-SQL and `unused_export` false positives; status reports `not_computed` instead of a perfect biomarker score when no detector run exists (#133).
- Dependency updates include `blake3` 1.8.6, `clap` 4.6.6, `ignore` 0.4.33, `tree-sitter` 0.26.12, and `thiserror` 2.0.20.

## Upgrade

Run `cartograph upgrade --apply --project-path <PATH> --json` and require `completed: true`. Reopen the agent host only when the report sets `restartRequired: true`.

**Compatibility:** schema 38 · contract V14 · PostgreSQL 18.4+, `pg_search` 0.25.1, pgvector 0.8.4+ (managed bundles 0.8.4; 0.8.6 recommended for external).
