# Cartograph v2.1.19

Cartograph v2.1.19 fixes two indexing failures reported against v2.1.18; it was a tag-only candidate superseded by v2.1.20.

## Changes

- Slang grammar-recovery nodes no longer create invalid spans. Affected files are kept partial with `extraction_invalid_span` or `extraction_parser_stopped`, and the rest of the generation publishes (#139).
- `generationStorage: "auto"` now selects PostgreSQL spill at 64 Cargo manifests, so roughly 100-crate Rust workspaces no longer exhaust the in-memory bound (#140).
- Capacity errors name the limit, scope, and next action; MCP admin jobs add `failureDetail` fields. `maxGenerationBytes` is documented as a Cartograph-process bound.

## Upgrade

Install v2.1.20, which ships the same fixes. Run `cartograph upgrade --apply --project-path <PATH> --json` and require `completed: true`.

**Compatibility:** schema 38 (unchanged) · contract V14 (unchanged) · native Rust, PostgreSQL-only; release archives bundle no database or container image.
