# Cartograph v3.0.4

This release improves hybrid retrieval and makes Rust test discovery consistent
across indexing, search, and affected-test selection.

## Changes

- Rerank the merged lexical and semantic shortlist with bounded source excerpts
  from one generation snapshot; preserve original scores and fail-open behavior.
- Clean natural-language queries and add bounded code aliases while preserving
  quoted names, qualified identifiers, and the original query for models.
- Recognize Rust `test.rs` and `tests.rs` consistently and retain real caller
  edges for affected-test discovery.
- Add a reproducible 60-query retrieval evaluation. In one repository pilot,
  hybrid hit@5 rose from 27/60 to 30/60; BM25 results were mixed. These are
  repository-specific observations, not a general accuracy or speed guarantee.

## Upgrade

Stop the existing native owner cooperatively, then run
`cartograph upgrade --apply --project-path <PATH>` and require `completed: true`.
Start the new owner, check status, and reopen attached MCP hosts. V24 requires
one ordinary reindex even when source is unchanged; refresh embeddings if
semantic readiness requests it.

**Compatibility:** native RocksDB format v1 · generation contract V24 · Rust
1.99.1 / edition 2024. Existing native generations remain readable.
