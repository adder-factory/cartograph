# Cartograph v2.1.16

Cartograph v2.1.16 clears the eleven code-health findings carried by v2.1.15 by restructuring Rust code paths while preserving public behavior.

## Changes

- C-family extraction (C, C++, CUDA, Objective-C, Slang) is split into separate recognition, emission, type, scope, and body steps; extracted facts are unchanged.
- Invocation capture isolates Rust receiver resolution, oversized Go selectors, and JavaScript dynamic dispatch.
- MCP admin-job and tool errors route through focused classifiers; a regression table locks the existing error codes and redacted messages.
- No detector was suppressed, no severity changed, and no source was excluded.

## Upgrade

Run `cartograph upgrade --apply --project-path <PATH> --json` and require `completed: true`. Reopen the agent host only when the report sets `restartRequired: true`.

**Compatibility:** schema 38 (unchanged) · contract V14 (unchanged) · native Rust, PostgreSQL-only; release archives bundle no database or container image.
