# Cartograph v3.0.3

This release builds Cartograph with Rust 1.99.1 and refreshes TLS certificate
validation while preserving existing native RocksDB generations.

## Changes

- Upgrade the pinned compiler, workspace Rust minimum, compatibility facade,
  CI, and both Linux build images to Rust 1.99.1; retain edition 2024.
- Include Rust's fixes for x86-64 FFI `bool` return values, the macOS linker,
  and missing `wcslen` symbols on affected targets.
- Update rustls-webpki to 0.103.16, which rejects certificate paths containing
  newly distrusted intermediate public keys.
- Audit all 90 direct dependencies, 288 resolved registry crate names, six
  GitHub Actions, and the pinned Debian runtime images.

## Upgrade

Run `cartograph upgrade --apply --project-path <PATH>` and require
`completed: true`. Restart an existing native owner and reopen attached MCP
hosts when their pinned executable changes.

**Compatibility:** native RocksDB format v1 · generation contract V23 · Rust
1.99.1 / edition 2024. Existing native generations remain readable.
