# Cartograph v3.0.0

Cartograph 3.0 stores each project's code graph in embedded RocksDB and keeps it current through a persistent native owner.

## Changes

- Replace PostgreSQL, SQLX, ParadeDB, pgvector, and managed database containers with per-project RocksDB 11.8.1 compiled into the Rust executable.
- Add persistent `service start|stop|status`, shared Unix owner IPC, incremental file parsing, a 150 ms watcher quiet window, and explicit freshness/failure diagnostics.
- Run blocking storage work on bounded dedicated workers behind async Rust APIs, with snapshot readers, synchronous WAL commits, atomic changed-record publication, packed adjacency, and resumable retention.
- Retain exact/BM25/hybrid retrieval, graph traversal, review, numerical evidence, SCIP, artifacts, sessions, and optional local models through typed native services.
- Cache validated optional Jev decisions with bounded admission, deadlines, generation-aware identity, background fairness, and explicit cache/token accounting.
- Keep coherent graph context available across concurrent publication, with explicit stale evidence and no code windows when their generation changes.

## Upgrade

For v2 projects, install v3 with the release installer, then run `cartograph db migrate --to rocksdb --project-path <PATH>` and `cartograph upgrade --apply --project-path <PATH>`. Migration rebuilds from source and preserves the old database; legacy notes, sessions, vectors, and artifacts are not imported. Rebuild embeddings when configured, stop any old native owner before reconciliation, then restart it and reopen attached MCP hosts. macOS provides `service stop|start`; on Linux use your user service manager.

See the [migration guide](https://github.com/adder-factory/cartograph/blob/main/docs/v2/ROCKSDB-MIGRATION.md) for verification and limitations. Windows supports one primary process per project; Unix clients can share the persistent owner. BM25 uses generation-scoped postings with a bounded scan fallback; exact cosine retrieval scans bounded vectors.

**Compatibility:** native RocksDB format v1 · generation contract V23 · Rust 1.99.0 / edition 2024 · macOS 26+ (ARM64), Linux glibc 2.41+ (ARM64/x64), Windows x64. No PostgreSQL or SQLite runtime remains.
