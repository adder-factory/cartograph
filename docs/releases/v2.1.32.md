# Cartograph v2.1.32

Cartograph v2.1.32 improves automatic index recovery, fixes several Jev and exploration issues, and requires ParadeDB 0.25.10.

## Changes

- Source edits during indexing and contention with another writer schedule bounded retries after 2–30 seconds, even without a new filesystem event; these do not count as persistent failures.
- Jev receives bounded native source windows plus symbol kinds and line ranges; caller/callee operations are offered only for functions and methods (#164, #165).
- `--low-tokens` returns at most eight compact evidence rows within 16 KiB, without source excerpts or decision-provider calls (#166).
- Missing Jev credentials name the configured environment variable (#167). Graph hops expose stored edge source and target IDs separately from traversal order (#168).

## Upgrade

An existing 0.25.9 service needs a coordinated database upgrade: run `cartograph upgrade --apply --project-path <PATH> --json`; if it reports `upgrade-managed-database`, follow its backup and confirmed replacement steps, then rerun until `completed: true`. External administrators must update `pg_search` to 0.25.10; reopen MCP hosts when required.

**Compatibility:** schema 44 (unchanged) · contract V18 (unchanged) · `pg_search` 0.25.10 (exact); managed image PostgreSQL 18.6, pgvector 0.8.4.
