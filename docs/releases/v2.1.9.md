# Cartograph v2.1.9

Cartograph v2.1.9 fixes large immediately invoked Rust closures blocking publication and aligns `cartograph_review` with its published schema.

## Changes

- Immediately invoked Rust closures are treated as anonymous call targets; calls inside them stay indexed.
- Over-long reference names report `reduce/reference_name_too_long` (CLI) or `reduce_reference_name_too_long` (MCP, auto-sync). Failures keep their real parse, resolve, overlay, or reduce stage.
- `cartograph_review` context mode accepts `pathFilter` (a segment prefix, so `src` does not match `src2`) and `allowStale`.

## Upgrade

Run `cartograph upgrade --apply --project-path <PATH>`; an unchanged V10 graph stays stale until an index publishes V11.

**Compatibility:** schema 30 · contract V11 · PostgreSQL 18, `pg_search` 0.25.0, pgvector 0.8.4+.
