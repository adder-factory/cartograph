# Cartograph v2.1.23

Cartograph v2.1.23 fixes model endpoint probing, makes biomarker computation explicit and non-blocking, and bounds dead-code and digest queries.

## Changes

- `doctor` probes `/v1/models` for endpoints already ending in `/v1` instead of `/v1/v1/models`, using the same normalizer as embedding and reranking (#147).
- Biomarker reads and status no longer trigger whole-generation computation; they return `not_computed` until `cartograph admin biomarkers-refresh --no-dry-run --confirm` runs (#148).
- Dead-code queries limit candidates before enrichment; a statement timeout returns `dead_code_query_timeout` with retry guidance (#149).
- Digest keeps successful sections when one times out or fails; `sectionStatus` reports each section and `degraded` marks a partial digest.

## Upgrade

Run `cartograph upgrade --apply --project-path <PATH> --json` and require `completed: true`. Restart the agent host only when the report says `restartRequired: true`.

**Compatibility:** schema 39 (unchanged) · contract V14 (unchanged).
