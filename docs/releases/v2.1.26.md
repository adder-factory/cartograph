# Cartograph v2.1.26

Cartograph v2.1.26 is a corrective release that fixes the version published to SonarQube.

## Changes

- `sonar.projectVersion` now matches the Cargo workspace version used by the binary, signed tag, release notes, and GitHub release.
- A required release-workflow contract fails the release when the two versions differ or the Sonar version is missing or duplicated.
- No database migration, generation-contract, retrieval, dependency, or managed-container change from v2.1.25.

## Upgrade

Run `cartograph upgrade --apply --project-path <PATH> --json` and require `completed: true`. Restart the agent host only when the report says `restartRequired: true`.

**Compatibility:** schema 39 (unchanged) · contract V14 (unchanged) · PostgreSQL 18, `pg_search` 0.25.3, managed pgvector 0.8.4.
