# Cartograph v2.1.41

Cartograph v2.1.41 restores v1's cross-file resolution: references now reach the declaration they name in many more languages, checked against v1's real resolved targets.

## Changes

- TypeScript/JavaScript: `tsconfig`/`jsconfig` `extends` chains, JSONC configs, conventional and workspace-package aliases (`exports`, conditions, `types`/`main`), barrel re-exports, implicitly public class methods, imported static members and framework-convention calls; React Native and Expo calls keep their native targets.
- Python absolute and package imports, explicitly typed receivers (`self`, typed parameters and fields, constructors) and proven base classes; Go typed receivers and fields.
- Java/Kotlin explicit and wildcard imports, nested and local types, static members and Kotlin↔Java calls; C# namespaces, `using` directives and constructors; enum members; Rust workspace, `crate`/`self`/`super` paths and renamed Cargo dependencies.
- Shell `source`/dot-source calls, Elixir module calls, current-class and recursive calls, Salesforce (LWC Apex imports, Visualforce/Aura controllers), Play routes, PHP controllers and CodeIgniter routes.
- Resolution never guesses: shadowed names, aliases, overloads and unproven scopes stay unresolved, and labeled fallbacks carry lower confidence.
- An exact v1 resolution oracle checks 1,724 cross-file facts from v1.1.33: 896 match exactly or by pinned shape, 406 are intentional v2 corrections, and 422 remain pending for v2.1.42.

## Upgrade

Run `cartograph upgrade --apply --project-path <PATH>`; it migrates the schema and publishes each project's replacement generation. Existing V21 indexes rebuild once even when source is unchanged; no database service upgrade is needed from v2.1.40.

**Compatibility:** schema 49 · contract V22 · ParadeDB 0.26.0, pgvector 0.8.6 (unchanged).
