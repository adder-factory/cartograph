# Cartograph v2.1.36

Cartograph v2.1.36 records Rust references inside macro arguments, keeps SCIP import failure outcomes, and redacts secrets from Debug output.

## Changes

- Calls, qualified paths, nested macros, and format captures such as `{LIMIT}` inside `format!`, `assert_eq!`, and similar macros are recorded, so items used only there stop being `unused_export`.
- `matches!`-family patterns publish what a `match` arm publishes. One macro call may now produce up to 8,192 references instead of 1,024.
- `scip-import` keeps its index `failure`, `cancelled` status, and `cleanupFailure` when the overlay restore fails; the restore error appears as optional `overlayRollbackFailure` (`scip_overlay_rollback_failed`).
- Debug output of parsed commands redacts database URLs, API-key arguments, endpoints, and CLI bridge arguments.

## Upgrade

Run `cartograph upgrade --apply --project-path <PATH>`; it migrates the schema and publishes a replacement generation. Existing V18 indexes rebuild once (unchanged checkouts report `fresh: false` until then); no database service upgrade is needed from v2.1.35.

**Compatibility:** schema 46 · contract V19 · ParadeDB 0.25.11 (unchanged).
