# Cartograph v3.0.2

This release refreshes native Rust dependencies while preserving the per-project
RocksDB storage and generation contracts.

## Changes

- Update Tokio to 1.54.0, Jiff to 0.2.38, and libc to 0.2.191.
- Refresh seven transitive dependencies, including native build tools and
  platform certificate support.
- Incorporate the dependency updates proposed in PR #191 while preserving
  compatible Syn and Windows selections under the duplicate-package gate.
- Audit all 90 direct external dependencies, GitHub Actions, and pinned build
  images; retain the reviewed RocksDB 11.8.1 binding and Rust 1.99.0 toolchain.
- Isolate startup and bounded Git test fixtures from ambient events and
  templates while retaining real watcher and subprocess coverage.

## Upgrade

Run `cartograph upgrade --apply --project-path <PATH>` and require
`completed: true`. Restart an existing native owner and reopen attached MCP
hosts when their pinned executable changes.

**Compatibility:** native RocksDB format v1 · generation contract V23 · Rust
1.99.0 / edition 2024. Existing native generations remain readable.
