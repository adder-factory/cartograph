# Cartograph v2.1.28

Cartograph v2.1.28 makes generation retention resumable, improves Rust caller resolution, and upgrades Rust, Tree-sitter, and ParadeDB.

## Changes

- Retention moves eligible generations to `retiring` and drains them in committed batches of at most 10,000 rows, so progress survives a later timeout.
- Parse-cache maintenance runs even when generation cleanup fails. `db usage` reports retiring work and repeated failures; new `db prune --maximum-search-relation-bytes` (capped at 64 GiB).
- Rust `self` receivers resolve across split implementation files, parent modules, and supported aliases; ambiguous or unknown receivers stay unresolved.
- Dependencies: Rust 1.98.1, Tree-sitter 0.27.0, Arborium grammars 2.18.2, ABAP bindings 31.0.0, managed ParadeDB 0.25.6. Yanked packages now fail the dependency gate.

## Upgrade

Run `cartograph upgrade --apply --project-path <PATH> --json`; if it requests a managed database upgrade, back up, ensure free space, quiesce writers, run the confirmed `db upgrade`, and resume until `completed: true`. Existing storage backlogs need bounded pruning afterward; never delete PostgreSQL data files by filename.

**Compatibility:** schema 42 · contract V16 · `pg_search` 0.25.6; managed image PostgreSQL 18.6, pgvector 0.8.4 (0.8.6 recommended for external).
