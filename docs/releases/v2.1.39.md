# Cartograph v2.1.39

Cartograph v2.1.39 refreshes the Rust dependencies and moves the managed database to ParadeDB 0.26.0 with pgvector 0.8.6.

## Changes

- The digest-pinned managed image now supplies PostgreSQL 18.6, `pg_search` 0.26.0, and pgvector 0.8.6 on Linux amd64 and arm64.
- The managed upgrade updates pgvector before `pg_search` in one transaction. Existing `bm25` indexes remain supported.
- Live upgrade tests now cover upgrading from 0.25.11, including interrupted container replacement and rollback; the 0.25.3, 0.25.6, and 0.25.10 paths stay covered.
- Dependency refresh: `libc` 0.2.190, `signal-hook` 0.4.5, Tokio 1.53.2, `cc` 1.6.0, `mio` 1.2.4. Rust stays pinned at 1.99.0. See the [dependency audit](https://github.com/adder-factory/cartograph/blob/main/docs/v2/DEPENDENCY-UPDATE-2026-10-04.md).

## Upgrade

Run `cartograph upgrade --apply --project-path <PATH>`. When it requests a managed database upgrade, follow the reported backup and confirmed replacement steps, rerun the same command, and reopen the agent host if a restart is reported.

**Compatibility:** schema 47 (unchanged) · contract V20 (unchanged) · external PostgreSQL 18.4+ (major 18), `pg_search` 0.26.0, pgvector 0.8.4+ (0.8.7 recommended); managed uses pgvector 0.8.6.
