# Cartograph v2.1.39

Cartograph v2.1.39 updates the native Rust dependencies and advances the managed
database to ParadeDB 0.26.0 with pgvector 0.8.6.

## Dependency refresh

All 87 direct registry dependencies were checked against their newest stable
versions. Updates include `libc` 0.2.190, `signal-hook` 0.4.5, and Tokio 1.53.2.
The lockfile also advances the C/C++ build helper `cc` to 1.6.0 and the I/O
polling dependency `mio` to 1.2.4. Rust remains pinned to stable 1.99.0; the
release build images and GitHub Actions already match their current stable pins.

## ParadeDB 0.26.0

The digest-pinned managed image now supplies PostgreSQL 18.6, `pg_search`
0.26.0, and pgvector 0.8.6 on both Linux amd64 and arm64. CI, development
Compose, capability checks, and installation documentation use the same image.

The managed upgrade updates pgvector before `pg_search` in one transaction.
Existing `bm25` indexes remain supported. The live upgrade suite now explicitly
covers 0.25.11, including interruption between container rename and replacement,
rollback before extension mutation, and recovery after extension mutation. The
earlier 0.25.3, 0.25.6, and 0.25.10 upgrade paths remain covered.

Run `cartograph upgrade --apply --project-path <PATH>`. When it requests a
managed database upgrade, follow the reported backup and confirmed replacement
steps, then rerun the same command to complete reconciliation. Reopen an
attached agent host when the upgrade reports that a restart is required.

## Compatibility

The schema remains **47** and the generation contract remains **V20**. External
databases require PostgreSQL 18.4 or newer within major version 18, `pg_search`
0.26.0, and pgvector 0.8.4 or newer; pgvector 0.8.7 is recommended. Managed
databases use the exact bundled pgvector 0.8.6 version.

Cartograph remains a native Rust, PostgreSQL-only executable. Release archives
contain no PostgreSQL, ParadeDB, pgvector, database, or container image.

The [dependency audit](../v2/DEPENDENCY-UPDATE-2026-10-04.md) records the selected
versions and published image digests.
