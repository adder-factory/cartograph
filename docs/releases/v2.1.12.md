# Cartograph v2.1.12

Cartograph v2.1.12 stores structural findings, shortens over-long names instead of failing, adds flexible exclusions, and indexes WGSL and Metal.

## Changes

- Structural findings are computed once per input fingerprint and stored (schema 37); `cartograph_status` reads stored rows and reports `pending` / `not_computed` before the first computation.
- Over-long synthesized names are shortened deterministically with a `canonical_name_truncated` diagnostic instead of discarding the generation; unshortenable fields report `canonical_field_rejected(<field>)` (#118, #119).
- Exclude paths with `exclude` in `.cartograph/config.json`, repeatable `cartograph index --exclude <GLOB>`, or `.cartographignore`; `!` re-includes. Metrics report `excluded_paths` and `excluded_trees` (#120).
- WGSL extraction, with shader entry points listed by `entry-points`, and Metal via the C-family extractor; the registry now has 128 modes (#121).
- The repository's own code-health findings drop to zero at every severity, from 7 errors, 32 warnings, and 39 info.

## Upgrade

`cartograph upgrade --apply` applies schema migration 37. The first `cartograph_status` afterward reports `biomarkers: pending` until the first `cartograph biomarkers` call computes the relation.

**Compatibility:** schema 37 · contract V13 (unchanged).
